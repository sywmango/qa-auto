# 상단 공통 기능 오류 목록

마지막 확인: 2026-10-22 (QA, 최신영 계정)

- 동작 확인: `tests/common/header.spec.ts` (대표 메뉴 정기점검주기, `.\run-common.ps1 header`)
- 업무그룹: 업무그룹설정(개인설정)과 함께 확인. 테스트가 `[sychoi] 자동테스트` 업무그룹을 만들어 쓰고 끝에 지움
- 메뉴별 아이콘 확인: `tests/menu-all.spec.ts` (전체 메뉴 192개, `.\run-tests.ps1 menu-all`)
- 규칙: 즐겨찾기·업무그룹·편집모드 아이콘은 모든 화면, Tab설정 아이콘은 위쪽 탭이 있는 화면만 (189개 메뉴가 이 규칙과 맞음)

## 오류

| # | 화면 | 조건 | 결과 | 기대 |
| --- | --- | --- | --- | --- |
| 1 | 공통 (정기점검주기에서 확인) | 편집모드에서 검색 필드를 끌어 옮기고, 3초 안에 자물쇠로 편집모드를 끔 | 다시 열면 원래 순서. 저장 요청이 가지 않음 (놓고 3초 뒤 자동 저장, 상세 화면은 10초 넘게 걸리기도 함). 사용자 추가 확인 예정 | 편집모드를 바로 꺼도 옮긴 순서가 저장됨 |
| 2 | 통합센터 > Process센터 | 메뉴를 연다 / 업무그룹설정에서 업무그룹에 이 화면을 넣고 왼쪽 업무그룹 화면을 연다 | 상단에 업무그룹 아이콘이 없음. 업무그룹설정에는 들어가지만(화면ID processRptAll) 업무그룹 화면의 탭이 빈칸 (사용자 확인, 자동 테스트로 재현) | 업무그룹 아이콘이 보이고, 업무그룹에 넣으면 화면이 열림 |
| 3 | 통합센터 > Layout센터 | 2번과 같음 | 2번과 같음 (화면ID layoutRpt) | 2번과 같음 |
| 4 | 개인설정 > 개인정보 | 메뉴를 연다 | 위쪽 탭이 없는데 Tab설정 아이콘이 보임 | 위쪽 탭이 없는 화면은 Tab설정 아이콘이 없음 (다른 화면과 같게) |

## 참고

- 정상: 즐겨찾기 별을 누르면 왼쪽 즐겨찾기 목록에 메뉴 이름이 바로 추가되고, 다시 누르면 빠짐. 업무그룹 아이콘으로 넣은 화면은 업무그룹설정 업무화면과 왼쪽 업무그룹 화면에 나오고, 업무그룹설정에서 넣은 정기점검주기 화면도 업무그룹 화면에서 정상으로 열림.

- 정상(사양): 위쪽 탭 Tab설정 팝업에서 [Edit] 칸이 모두 읽기전용. 순서는 편집모드로만 바꾸고, 되돌리기는 [초기화].
- 별개: 보고서관리 > 사용자정의 > 설비조회는 메뉴 번호 2989 를 찾지 못해 열리지 않음 (상단 기능과 상관없음, 메뉴 목록 변경 확인 필요).
