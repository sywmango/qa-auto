## 3. 새 메뉴를 할 때

1. `tests/screens/<화면ID>.ts` 에 `view` 를 적는다 (검색 DTO, 목록 기준 열, 비교 조건, 상세 프레임·칸).
2. `RUN_<화면ID>=1` 로 `npx playwright test common/screen` → 공통 케이스 약 15~18건이 바로 돈다.
3. 메뉴 코드에는 그 메뉴에만 있는 규칙만 짠다.
