## 3. 범위

**한다**
- 탭 5개: 카렌다(연간) / 카렌다(월간) / 목록(위치) / 목록(종류) / 목록(조건)
- 조회(검색, 카렌다 건수, 트리, 정렬, 표시형식, 상세, Excel, 하위 탭)
- 일정추가·작업일자 수정·Edit(일정조정·비고)·일정확정·삭제 + 정리
- 점검작업 수정·필수값·점검값·첨부문서·Linked·완료처리, 오류 캡처
- 공통테스트 적용: 예 (`tests/screens/ad210.ts`)

**하지 않는다**
- 주기 자체 생성·삭제 (AD230 에서)

## 5. 판정 규칙

**기대값 계산**
- Scheduled = 작업발행, Completed = 작업완료. 카렌다 숫자(P/S/C)와 아래 목록 건수가 같아야 함.

**확인된 사양 (오류 아님)**
- 2026-10-21: 일정추가에서 지난 날짜 생성 허용 (EC_002). 팝업 안내 문구는 권고일 뿐.
- 2026-10-21: 상세에서 지난 작업일자로 변경 허용 (EC_006).
- 2026-10-21: 종료가 시작보다 앞이면 종료일자가 지워짐 (EC_008).
- 2026-10-21: 체크 없이 일정확정 → 목록 조회 후 '선택된 데이터가 없습니다.' (TC_032).
- 2026-10-21: Tab 설정 [초기화] 바로 반영 → TC_027 정상.

**알려진 오류·개선** (2026-10-21, v3)
- 오류 TC_016: 목록(위치)·(종류) 완료일자 '20261019' 형식 (기대 yyyy-mm-dd)
- 오류 TC_024: 카렌다(연간) [삭제] 동작 안 함 (목록(조건)은 정상)
- 개선 TC_030·037, EC_011: 계획일자 없이 저장 / 점검명 없이 확정 / 점검명 길이 초과 → 안내 없음
