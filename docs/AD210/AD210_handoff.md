# 정기점검계획(AD210) 단위테스트 — 다시 돌리는 법

마지막 정리: 2026-10-21. 결과는 `docs/AD210/AD210_UT_정기점검계획_v3.xlsx`, `docs/AD210/report/AD210_정기점검계획_테스트결과보고서_v3.pdf`
(59건: 정상 54, 오류 2, 개선 3). 이전 버전은 `docs/AD210/이전버전/`. 케이스 원본은 `docs/AD210/cases.json` → `scripts/build-ut-sheet.py` 로 양식 엑셀을 만듦.

## 1. 한 번에 돌리기

D:\qa-auto 에서 PowerShell:

```
.\run-ad210.ps1          # 전체: 조회 → Setting → 계획 데이터 → 점검작업 → 오류 캡처 → 엑셀·PDF (약 1시간)
.\run-ad210.ps1 view     # 조회만 (데이터 안 바뀜, 약 20분)
.\run-ad210.ps1 report   # 이미 돌린 결과로 엑셀·PDF 만 다시
```

- AD210 테스트는 `RUN_AD210=1` 일 때만 돈다 (평소 `.\run-tests.ps1` 에서는 빠짐).
- 로그인은 `playwright\.auth\user-ad210.json` 에 따로 저장 (`QA_AUTH`). 같은 계정(최신영)으로 다른 테스트를 동시에 돌리면 세션이 끊긴다 → 한 번에 하나만.
- QA 서버 재배포 중에는 `/dream/index.do` 가 404 → 다시 뜬 뒤 실행.

## 2. 테스트 데이터

- [sychoi] 주기 8007 / 설비 100302AG13 에 일정추가로 계획을 만들어 씀. 작업계획으로 남은 것은 `plan-data` 마지막 "정리" 가 지움.
- 확정(작업발행)·완료한 계획은 지울 수 없어 남음: 2026-12-18 (작업발행), 2026-10-20 (작업완료). 8007 계획은 2026-10-21 아침에 다시 생성돼 있었음(12-18 이 작업계획으로 돌아가 있어 다시 확정).
- 작업완료 건 확인용으로 예전 주기 8018 (2026-10-22 작업완료) 을 씀 (바꾸지 않음).
- Setting 은 바꾼 뒤 원래대로 되돌림 (사용자별 저장). Tab 설정은 [초기화] 가 다시 로그인해야 반영되므로 Edit 로 Y 저장해서 되돌림.

## 3. 화면 동작 (자동화할 때 주의)

- 탭: 카렌다(연간) / 카렌다(월간) / 목록(위치) / 목록(종류) / 목록(조건). 년·년월 칸은 읽기전용(선택기) → 값 + change 이벤트로 넣음.
- 카렌다 숫자(P/S/C)를 눌러야 아래 목록이 나옴. Scheduled = 작업발행, Completed = 작업완료.
- 행 클릭 상세: 작업계획 → 일정 상세(작업일자만 수정), 작업발행·완료 → 점검작업 상세(확정·저장·Linked).
- 점검작업 상세의 점검항목·표준작업·첨부문서는 아코디언(모두 펼쳐짐). 탭 글자를 누르면 접힘.
- 점검값은 점검항목 행 클릭 → `workPmiPointValueDetail` 의 점검값 칸.
- 일정추가 팝업: 일정추가하기를 누르면 예방작업설비선택 Lov 가 같이 열림. 계획일자 칸(달력)은 글자로 안 들어가고 Date 로 넣어야 함.
- 일정확정하기 확인창은 목록 프레임 안에 뜸 (메인 화면이 아님).
- Edit: 바꿀 수 있는 칸은 날짜(일정조정, 달력)와 비고. 비고 칼럼은 기본 Setting 에서 숨겨져 있음.
- 목록(조건)·카렌다 목록의 비고·측정시간·사용량 칼럼은 기본 Setting 에서 숨김.

## 4. 판정 (사용자 확인 2026-10-21)

| ID | 결과 | 내용 |
| --- | --- | --- |
| TC_016 | 오류 | 목록(위치)·(종류) 완료일자 '20261019' 형식 |
| TC_024 | 오류 | 카렌다(연간) 탭 [삭제] 동작 안 함 (목록(조건)은 정상) |
| TC_027 | 정상 | Tab 설정 [초기화] 가 2026-10-21 재배포 후 바로 반영 (v3 에서 개선 → 정상) |
| TC_030·037 | 개선 | 계획일자 없이 저장, 점검명 없이 확정 → 안내 없음 |
| EC_011 | 개선 | 점검명 길이 초과 안내 없음 (정기점검주기와 같음) |

사양 확인: 일정추가에서 지난 날짜 생성 허용(EC_002), 상세에서 지난 작업일자로 변경 허용(EC_006), 종료가 시작보다 앞이면 종료일자가 지워짐(EC_008), 체크 없이 일정확정은 목록을 조회한 뒤 '선택된 데이터가 없습니다.'(TC_032).

판정을 바꾸려면 `docs/AD210/report/판정기준.json` 을 고치고 `.\run-ad210.ps1 report`.
