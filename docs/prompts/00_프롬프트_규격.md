# 프롬프트 md 규격

마지막 정리: 2026-10-23

Claude에게 테스트를 맡길 때 쓰는 프롬프트 md는 모두 이 규격을 따른다.
같은 칸이 같은 순서로 있어야 Claude가 빠짐없이 읽고, 빈 칸이 있어도 "기본값"으로 채워 질문 없이 진행할 수 있다.

## 1. 파일 종류와 위치

| 종류 | 파일 | 언제 |
| --- | --- | --- |
| 규격 (이 문서) | `docs/prompts/00_프롬프트_규격.md` | 프롬프트를 새로 만들거나 고칠 때 |
| 공통테스트 | `docs/prompts/공통테스트.md` | 모든 메뉴에 똑같이 있는 기능 (Setting, 상단 공통, 전체 메뉴 점검) |
| 메뉴테스트 템플릿 | `docs/prompts/메뉴테스트_템플릿.md` | 새 메뉴를 시작할 때 복사 |
| 메뉴별 프롬프트 | `docs/<화면ID>/<화면ID>_prompt.md` | 템플릿을 복사해 그 메뉴 내용만 채운 것 (예: `docs/AD230/AD230_prompt.md`) |
| 공통 기본값 | 저장소 맨 위 `CLAUDE.md` | Claude가 매번 자동으로 읽음. 모든 프롬프트에 공통인 기본값·질문 기준 |

- 메뉴별 프롬프트에는 **그 메뉴만의 내용**만 쓴다. 공통 규칙(테스트 데이터 이름, 결과 표기, 되돌리기 등)은 `CLAUDE.md` 에 한 번만 쓰고 반복하지 않는다.
- 공통 기능 테스트 방법은 `공통테스트.md` 에만 쓴다. 메뉴별 프롬프트에서는 "공통테스트 적용: 예/아니오"와 대상만 적는다.

## 2. 칸 (모든 프롬프트 md 공통, 이 순서 그대로)

| # | 칸 | 쓰는 내용 | 비워 두면 |
| --- | --- | --- | --- |
| 0 | 머리 | 제목, 화면ID, 메뉴 경로, 마지막 정리 날짜, 버전 | 작성 불가 (필수) |
| 1 | 목적 | 이번 테스트로 무엇을 확인하는지 한두 줄 | "단위테스트 전체 수행" |
| 2 | 입력 자료 | 업무 규칙·로직 문서, 설계서, 테이블 정의, 예전 UT 양식의 경로 | 화면 탐색 결과만으로 케이스 작성 |
| 3 | 범위 | 할 것 / 하지 않을 것 (탭, 기능, 단계) | 화면에 보이는 모든 기능 |
| 4 | 테스트 데이터 | 쓸 데이터(주기·설비·계획 번호), 새로 만들 데이터, 지우면 안 되는 데이터 | `CLAUDE.md` 기본값 |
| 5 | 판정 규칙 | 기대값 계산 방법, 이미 확인된 사양, 알려진 오류·개선 | 화면 동작과 일반 상식으로 판정, 애매하면 7번에 따라 질문 |
| 6 | 산출물 | 엑셀·PDF·코드·인수인계 문서 이름과 위치 | `CLAUDE.md` 기본 산출물 |
| 7 | 질문 기준 | 이 메뉴에서 **꼭 물어볼 것**, **묻지 말고 기본값으로 진행할 것** | `CLAUDE.md` 질문 기준 |
| 8 | 완료 조건 | 무엇이 되면 끝인지 (예: 엑셀·PDF 전달, PR 생성) | `CLAUDE.md` 완료 조건 |
| 9 | 실행 방법 | 다시 돌리는 명령 (`run-xxx.ps1` 단계) | 작업 끝에 Claude가 채움 |
| 10 | 변경 이력 | 날짜 / 바뀐 내용 / 누가 | 작업 끝에 Claude가 채움 |

## 3. 쓰는 법

- 문장은 짧게. 한 줄에 한 가지.
- 판정에 쓰는 값은 정확히 (날짜, 숫자, 버튼 이름 그대로). "~쯤", "적당히" 금지.
- 사양 확인처럼 사용자가 답해 준 것은 5번(판정 규칙)에 **날짜와 함께** 바로 적는다. 다음 실행에서 다시 묻지 않기 위함.
- 버튼·칸은 화면에 보이는 이름으로 적는다. 순서(몇 번째 버튼)로 적지 않는다.
- 비워 둘 칸도 지우지 않고 `(기본값)` 이라고 적는다. 칸이 없으면 빠뜨린 것인지 기본값인지 구분이 안 된다.

## 4. Claude가 프롬프트를 읽는 순서

1. `CLAUDE.md` (공통 기본값·질문 기준)
2. `docs/prompts/공통테스트.md` (공통 기능을 할 때)
3. `docs/<화면ID>/<화면ID>_prompt.md` (메뉴별)
4. 같은 폴더의 `<화면ID>_handoff.md`, `report/판정기준.json` (이전 결과가 있을 때)

뒤에 읽은 것이 앞의 것보다 우선한다. (메뉴별 프롬프트가 기본값과 다르면 메뉴별 프롬프트를 따른다.)
