## 3. 바꾸는 방법

1. **공통 테스트 파일 1개** `tests/common/screen.spec.ts`: 2번 표의 확인을 한 번만 짠다.
2. **화면 정의에 메뉴별 정보 추가** `tests/screens/<메뉴>.ts` (지금 Setting 용으로 있는 파일에 칸만 늘림):
   - 검색 필드(칸 ID, 기본값, Lov 원본 메뉴), 목록 기준 열, 상세 프레임, 읽기전용 칸, 필수 칸, 하위 목록
   - 공통 케이스 → 이 메뉴의 테스트ID 연결 (예: "검색 기본값" = AD230_TC_001). UT 엑셀 번호는 그대로.
3. **메뉴 코드에서 공통 부분 삭제**: `ad210/plan-view`, `ad230/pmi-cycle`, `ap591/exec-view` 등에서 2번 표의 케이스를 빼고 메뉴 고유 케이스만 남긴다.
4. **UT 케이스 목록**: 공통 케이스 문장 1벌 + 메뉴 고유 케이스. `build-ut-sheet.py` 가 둘을 합쳐 메뉴 UT 를 만든다.
5. **새 메뉴**: 화면 정의 하나만 쓰면 공통 케이스 약 20개가 바로 돈다.

## 4. 확인 방법

- 바꾼 뒤 AD230 하나로 oracle → mssql 순서로 돌려, 지금 결과(v17)와 같은 판정이 나오는지 비교한다. 같으면 AD210·AP591 도 옮긴다.
