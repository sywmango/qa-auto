## 3. 범위

**한다**
- 탭 2개: 카렌다(월간) (T 작업대상 / P 작업미완료 / C 작업완료) / 목록(조건)
- 조회(검색, 카렌다, 정렬, 상세, 표시형식, Excel, 점검항목·표준작업 탭)
- 점검작업 수정·점검값·Edit·첨부·Linked·확정, 오류·개선 캡처
- 공통테스트 적용: 예 (`tests/screens/ap591.ts`: 검색·상세 Field, Tab, 목록, 점검항목, 점검값 상세)

**하지 않는다**
- 주기 생성 (AD230), 일정 생성·확정 자체 판정 (AD210)

## 5. 판정 규칙

**기대값 계산**
- 점검결과 기본값 '정상' (Lov GD 정상 / BD 이상).
- 확정에는 점검시작·종료 일자, 점검값이 모두 있어야 함 ("점검값을 모두 입력해주십시오.").
- 목록(조건) 일정조정 일자 기본값 = 오늘 - 7일, 끝은 비어 있음.

**확인된 사양 (오류 아님)**
- 2026-10-21: 카렌다(월간) 년월은 읽기전용이라 비울 수 없음 → 필수 안내 없어도 정상 (TC_002).
- 2026-10-21: Setting Edit 범위 = Field 설정 정렬값·Display, 목록 정렬값·너비·Display (TC_025).
- 2026-10-21: 리스트 길이는 [초기화]로 안 돌아옴.
- 2026-10-21: 종료가 시작보다 앞이면 종료일자가 지워짐 (EC_004).

**알려진 오류·개선** (2026-10-21, v1)
- 오류 TC_024: 카렌다(월간) 검색 Setting 담당자·작업명 Display Y 인데 안 보임
- 개선 TC_027: 점검명 비우고 확정 → 안내 없음
- 개선 EC_005: 점검명 길이 초과 안내 없음
